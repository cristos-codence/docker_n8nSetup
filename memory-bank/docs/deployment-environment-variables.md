# n8n Deployment Environment Variables

This document contains the deployment configuration options for self-hosted n8n instances, including access URLs, templates, encryption, and server details.

## Overview

Environment variables allow you to configure various aspects of your n8n deployment without modifying code. This document provides a comprehensive reference for deployment-specific variables.

> **Note**: You can add `_FILE` to individual variables to provide their configuration in a separate file. For example, use `N8N_ENCRYPTION_KEY_FILE` instead of `N8N_ENCRYPTION_KEY` to load the encryption key from a file.

## Access Configuration

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `N8N_EDITOR_BASE_URL` | String | - | Public URL where users can access the editor. Used for emails sent from n8n and the redirect URL for SAML authentication. |
| `N8N_PATH` | String | `/` | The path n8n deploys to. |
| `N8N_HOST` | String | `localhost` | Host name n8n runs on. |
| `N8N_PORT` | Number | `5678` | The HTTP port n8n runs on. |
| `N8N_LISTEN_ADDRESS` | String | `0.0.0.0` | The IP address n8n should listen on. |
| `N8N_PROTOCOL` | Enum string: `http`, `https` | `http` | The protocol used to reach n8n. |
| `N8N_SSL_KEY` | String | - | The SSL key for HTTPS protocol. |
| `N8N_SSL_CERT` | String | - | The SSL certificate for HTTPS protocol. |
| `N8N_PROXY_HOPS` | Number | 0 | Number of reverse-proxies n8n is running behind. |

## Features and Customization

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `N8N_DISABLE_UI` | Boolean | `false` | Set to `true` to disable the UI. |
| `N8N_PREVIEW_MODE` | Boolean | `false` | Set to `true` to run in preview mode. |
| `N8N_TEMPLATES_ENABLED` | Boolean | `false` | Enables workflow templates (true) or disables them (false). |
| `N8N_TEMPLATES_HOST` | String | `https://api.n8n.io` | Change this if creating your own workflow template library. |
| `N8N_PERSONALIZATION_ENABLED` | Boolean | `true` | Whether to ask users personalization questions and customize n8n accordingly. |
| `N8N_VERSION_NOTIFICATIONS_ENABLED` | Boolean | `true` | When enabled, n8n sends notifications of new versions and security updates. |
| `N8N_VERSION_NOTIFICATIONS_ENDPOINT` | String | `https://api.n8n.io/versions/` | The endpoint to retrieve version information. |
| `N8N_VERSION_NOTIFICATIONS_INFO_URL` | String | `https://docs.n8n.io/getting-started/installation/updating.html` | The URL displayed in the New Versions panel for more information. |
| `N8N_HIRING_BANNER_ENABLED` | Boolean | `true` | Whether to show the n8n hiring banner in the console. |

| Variable | Type | Default | Description |
|----------|------|---------|-------------|

| `N8N_DIAGNOSTICS_ENABLED` | Boolean | `true` | Whether to share selected, anonymous telemetry with n8n. |
| `N8N_DIAGNOSTICS_CONFIG_FRONTEND` | String | `1zPn9bgWPzlQc0p8Gj1uiK6DOTn;https://telemetry.n8n.io` | Telemetry configuration for the frontend. |
| `N8N_DIAGNOSTICS_CONFIG_BACKEND` | String | `1zPn7YoGC3ZXE9zLeTKLuQCB4F6;https://telemetry.n8n.io/v1/batch` | Telemetry configuration for the backend. |

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `N8N_PUBLIC_API_DISABLED` | Boolean | `false` | Whether to disable the public API. |
| `N8N_PUBLIC_API_ENDPOINT` | String | `api` | Path for the public API endpoints. |

## Performance and System

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `N8N_PUSH_BACKEND` | String | `websocket` | Choose whether the n8n backend uses server-sent events (`sse`) or WebSockets (`websocket`) to send changes to the UI. |
| `N8N_GRACEFUL_SHUTDOWN_TIMEOUT` | Number | `30` | How long should the n8n process wait (in seconds) for components to shut down before exiting. |
| `N8N_DEV_RELOAD` | Boolean | `false` | Set to `true` to automatically reload when code changes (for development). |
| `N8N_REINSTALL_MISSING_PACKAGES` | Boolean | `false` | If set to `true`, n8n will automatically attempt to reinstall any missing packages. |

## Tunneling

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `N8N_TUNNEL_SUBDOMAIN` | String | - | Specifies the subdomain for the n8n tunnel. If not set, n8n generates a random subdomain. |

## Implementation Examples

### Basic Configuration

```dotenv
# Basic Server Setup
N8N_HOST=n8n.example.com
N8N_PORT=5678
N8N_PROTOCOL=https
N8N_SSL_CERT=/path/to/cert.pem
N8N_SSL_KEY=/path/to/key.pem

# Editor Access URL
N8N_EDITOR_BASE_URL=https://n8n.example.com

# Security
N8N_ENCRYPTION_KEY=your-secure-encryption-key
```

### Behind a Reverse Proxy

```dotenv
# Proxy Configuration
N8N_HOST=localhost
N8N_PORT=5678
N8N_PROTOCOL=http
N8N_EDITOR_BASE_URL=https://n8n.example.com
N8N_PROXY_HOPS=1
```

## Troubleshooting

### Common Issues

1. **Encryption Key Issues**: If you change the `N8N_ENCRYPTION_KEY` after initial setup, previously stored credentials will become unusable. Keep your encryption key secure and consistent.

2. **Base URL Problems**: If you experience authentication issues or broken redirects, ensure your `N8N_EDITOR_BASE_URL` is correctly configured with the full public URL.

3. **SSL Configuration**: When using HTTPS, both `N8N_SSL_KEY` and `N8N_SSL_CERT` must be provided and point to valid certificate files.

### Best Practices

- Use environment-specific configuration files for different deployments (development, staging, production)
- Store sensitive values in separate files using the `_FILE` suffix
- Consider using Docker secrets or a secure environment variable management system for production deployments
